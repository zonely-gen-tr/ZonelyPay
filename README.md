# ZonelyPay v1.0.0

ZonelyPay provides a self-hosted payment screen for WISECP and WHMCS.

- Configure your store's agreements and payment text and publish them automatically.
- Collect card details in a single screen for payment methods supported by the configured Weepay, PayTR and IBAN providers.
- Use HMAC signatures, key validation and IP checks to validate payment data.
- Send payment, refund and dispute emails automatically.
- Include a dispute-form link in the customer's payment email so they can contact you about a missing payment or request a refund.

Zonely.Gen.TR is available free of charge.
